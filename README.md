# Geomorphica Child Theme Plugin

## Version
2.0.0.1 for OJS 3.5

## Purpose
A simple theme plugin that makes custom styling available to the editorial interface for
the Geomorphica journal in order to hide certain workflow options that could interfere with
their review blinding processes, and injects custom JavaScript for front-end functionality.

## Dependencies
Requires and extends OJS' Default theme.

## Installing
- Place folder in the site's `plugins/themes` subfolder and set appropriate permissions.  
- Enable the plugin via Website > Plugins > Installed Plugins.
- Activate the theme via the dropdown at Website > Appearance > Theme.
